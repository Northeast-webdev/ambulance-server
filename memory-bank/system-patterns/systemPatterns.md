# Memory Bank: System Patterns

- **Backend**: Node.js with Fastify framework
- **Frontend**: Svelte-based SPA
- **Database**: Not fully determined from initial scan, likely uses a database for data persistence
- **API Pattern**: RESTful API endpoints

- Component-based architecture with Svelte
- Route-based organization (/routes directory)
- Stores for state management (Svelte stores)

## Backend Patterns

- Controller-based API structure
- Route definitions for API endpoints
- Schema definitions (likely for validation)
- PDF generation capabilities
- Image management for ambulance vehicles

## Integration Patterns

- Frontend-Backend communication via REST APIs
- Potential file uploads for image management
- PDF generation and serving

## Development Patterns

- Concurrent development setup
- Nodemon for backend hot-reloading
- Separate frontend and backend build processes
