# Memory Bank: Project Brief

## Project Overview

An ambulance management system with both backend and frontend components.

## Architecture

- **Backend**: Node.js with Fastify
- **Frontend**: Svelte-based application

## Key Components

- Backend API server for ambulance management
- Frontend web application interface
- PDF generation capabilities
- Image management for vehicles

## Project Goals

Provide a comprehensive ambulance service management system with tracking, scheduling, and reporting capabilities.

## Current Status

Existing project with established structure that requires maintenance and possibly enhancements.
